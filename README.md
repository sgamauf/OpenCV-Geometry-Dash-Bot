# OpenCV Geometry Dash Bot

> 🚧 **Work in Progress — Implementation Phase**

A Python project exploring computer vision and game automation using OpenCV.

## About the Project

The goal of this project is to develop a bot capable of detecting obstacles in Geometry Dash and automatically executing jumps at the appropriate time.

The bot will use image processing to identify spikes and rectangular blocks, estimate their positions and dimensions, and determine when the player needs to jump.

## Project Goals

- Detect obstacles using OpenCV.
- Identify obstacle positions, distances, and heights.
- Develop an algorithm for calculating jump timing.
- Automate jump inputs based on real-time gameplay.
- Explore the challenges of real-time computer vision.

## Planned Technologies

- Python
- OpenCV
- NumPy
- Linux (Wayland)
- Steam / Proton

## Current Status

**Phase: Milestone 1 — Offline Computer Vision**

Implementation has started with offline screenshot loading. The application can load a saved gameplay screenshot, report its dimensions, display it for visual inspection, and report loading failures.

Next steps focus on geometry calculations and experiments with block, spike, and player detection. Live capture, automatic jumping, and the monitoring UI are planned for later milestones.
